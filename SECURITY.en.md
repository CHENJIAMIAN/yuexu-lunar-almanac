# Security Policy

> [中文](SECURITY.md)

Yuexu does not process accounts, payment information, or cloud-based personal
data. Do not publish reproducible attack details for security issues. Once the
GitHub repository enables a private security channel, contact the maintainer
there.

Release packages should include SHA256 checksums. Windows SmartScreen, code
signing, and enterprise deployment policies are required checks before a formal
commercial release.
