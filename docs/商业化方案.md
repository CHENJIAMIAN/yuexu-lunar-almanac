# 月序商业化方案

## 产品定位

月序是面向 Windows 用户的低干扰桌面日历。基础体验是“全年可见、当天可知、电脑无负担”，不和待办、日程、天气或广告争夺注意力。

## 可售版本

| 版本 | 建议价格 | 交付内容 |
| --- | ---: | --- |
| 月序基础版 | 免费 / 开源 | 当前仓库的深浅主题、全年农历、每日更新 |
| 月序主题包 | 12-29 元 | 新的正版设计主题、节气插画、屏幕比例预设 |
| 月序 Pro | 39-59 元一次性 | 多显示器独立布局、节假日标记、字体与图标区避让、导入品牌色 |
| 团队部署 | 按设备报价 | 签名安装包、静默部署、企业主题、优先支持 |

开源基础版和付费交付并不冲突：用户购买的是设计、签名发行、稳定更新、部署能力和支持服务，不是对源代码的限制。

## 首发渠道

1. GitHub Release：建立信任、提供校验和与问题反馈入口。
2. 小红书、即刻、少数派：展示 4K 深浅主题实拍，突出低资源和农历可读性。
3. 爱发电、微信小店、数字商品平台：销售主题包与 Pro 授权。
4. 企业微信 / 飞书生态：面向企业行政或设计团队提供定制壁纸。

## 首发前必须完成

- 申请 Windows 代码签名证书，消除未知发布者提示。
- 准备 16:9、16:10、超宽屏三套截图和 30 秒演示视频。
- 建立购买、退款、主题包授权和隐私说明页面。
- 对 Pro 功能采用明确许可或账号交付，不在基础版中加入暗门或遥测。
