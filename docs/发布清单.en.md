# Release Checklist

> [中文](发布清单.md)

## Build

- [ ] `cargo test --locked` passes.
- [ ] `scripts/Build-Release.ps1` successfully generates a zip and `.sha256`.
- [ ] The release package contains `LunarCalendar.exe`, installer, uninstaller,
  ICO, README, LICENSE, VERSION, CHANGELOG, and manifest.

## Functionality

- [ ] All six built-in themes can be previewed and applied.
- [ ] Custom theme JSON can be exported, imported, and retained after restart.
- [ ] Color adjustments and top, bottom, left, and right margins preview in real
  time in the settings window; the desktop is unchanged until **Apply to
  Desktop** is selected.
- [ ] Desktop and Start Menu entries open the native settings window without
  starting a browser.
- [ ] Dark is the default theme, and the selected theme survives restart.
- [ ] Twelve months, leap months, Chinese New Year, and dates across calendar
  years are correct.
- [ ] 1920×1080 and 3840×2160 output has no cropping or horizontal offset.
- [ ] Scheduled-task updates do not start Chrome, Edge, or WebView.
- [ ] The logon task and daily 00:01 task are Ready after installation.
- [ ] Uninstallation removes tasks, protocol, and shortcuts but retains the
  current wallpaper.

## Commercial delivery

- [ ] The release zip's SHA256 is public.
- [ ] Code signing is complete, or its unsigned status is clearly stated.
- [ ] GitHub description, homepage, topics, screenshots, and the first Release
  are complete.
- [ ] Delivery and refund processes are ready for paid theme packs or Pro
  licenses.
